痛点真实性 痛点真实存在：大模型推理依赖昂贵 GPU 集群，「a trillion-parameter model should not require a trillion-dollar rack」。隐私敏感场景（医疗、法律、政府）存在本地推理刚需。但目标用户的付费意愿未被验证——本项目用户更多是技术爱好者与研究者在「酷炫」驱动下关注（6480 star），而非采购需求。

替代成本 替代路径众多：Moonshot AI 官方 API（低延迟、低成本）、llama.cpp 在 CPU 跑 7B-70B 小模型、GPU 云实例按需租用。对本项目目标场景（既有 1.56 TB 存储、又只有 8-32 GB 内存且拒绝联网）的用户，替代选择较少，但此类用户人群本身很小。

评估概述

安装部署与使用指南（D9 草稿）

上手难度等级：🟡 中等（6.0/10）
核心引擎的构建与无模型验证可在约 1 分钟内完成，但真正跑通 2.78T 模型需要下载 1.56TB 检查点并占用约 1.7TB 存储，部署门槛主要由数据规模构成，而非代码构建复杂度。以下给出关键步骤，省略基础操作细节。

环境要求（与 README「Requirements」一致）

  • OS：Linux x86-64（引擎目标平台；macOS/arm64 可 make，但需 Homebrew 的 libomp；不支持 Windows）
  • CPU：AVX2 + FMA（make portable 可生成通用 AVX2 二进制）
  • RAM：8 GB 起，所有 preset 均可运行，内存越多越快
  • 存储：约 1.7 TB 可用空间（1.56 TB checkpoint + 109 GB packed trunk），trunk 建议放在最快本地磁盘
  • 工具链：GCC ≥ 9 或 Clang ≥ 10，GNU make 或 CMake
  • Python 3.9+（仅用于下载、打包和分析工具，make test 不需要）

快速验证（无需模型、无需网络、无需 Python，约 1 分钟）

cd kimi-k3-in-c

make -j            # 秒级构建：七个 C 文件 + 编译器 + OpenMP
make test          # 1 分钟内跑完无权重测试套件

预期结尾：

VERDICT: ENGINE MATCHES THE REFERENCE EXACTLY

ALL WEIGHTLESS TESTS PASSED

完整部署到生成文本（6 步，仅第 4 步慢）

make -j
