二、安装部署与使用指南

项目类型说明: ip-as-logo-skill 是一个 Agent Skill（AI 代理技能包），非传统软件服务，无服务端部署需求。安装即以技能目录形式挂载到兼容的 AI agent 中运行。

环境要求: - Node.js 运行时（执行 npx 命令所需） - 任一兼容 AI agent：Codex、Coze、Doubao、YouMind、Manus、Gemini Apps、Replit Agent - 该 agent 需具备顶级图像生成模型（GPT Image 2、Seedance 5.0 Pro、Nano Banana Pro / Gemini Image Pro、Nano Banana 2 / Gemini Image Flash）。若缺失，需手动启用相应工具或提供 API key

安装步骤（单条命令）:

npx skills@latest add s1dashu/ip-as-logo-skill

安装器会自动检测仓库根目录的 SKILL.md，引导选择支持的 agent 并安装完整的 ip-as-logo 目录。如需跨项目全局安装：

npx skills@latest add s1dashu/ip-as-logo-skill --global

首次使用: 在已安装技能的 agent 中直接以自然语言提出需求，例如：

Create a very simple, cute rounded ghost IP character on a solid deep navy background.

技能会自动提案 3 个设计方向，用户确认后一次性生成 6 张独立候选图（A1/A2/B1/B2/C1/C2）。无需编写任何参数或配置文件。

解决完整度高：从读取产品仓上下文、问题收敛、三方向提案、六候选批量生成、到交付结果不自动重试，形成一条闭环的「AI 自主产出品牌吉祥物」管线。替代品（通用 AI 技巧、Canva 模板、雇佣设计师）体验/成本差异显著。
