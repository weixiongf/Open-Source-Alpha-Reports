一、部署方案概要

本项目是一个本地运行的单进程浏览器 Agent，官方未提供 Dockerfile / docker-compose / Helm / CI，因此部署形态只有一种：在本地机器上克隆源码 + 用 uv 安装 + 启动本地 Inspector 服务。它不是一个可上线的服务端产品，不需要数据库/缓存/消息队列，但强依赖本机 Chrome 浏览器与两个付费 API Key。

二、关键部署步骤

1）安装（单条 uv sync，无系统级依赖需手动安装）

git clone https://github.com/browser-use/jev-ultrafast.git
cd jev-ultrafast
uv sync
cp .env.example .env
# Add TYPESAFE_API_KEY and TEXT_MODEL_API_KEY.
uv run jev

2）访问本地 Inspector 并跑通 demo

打开 http://127.0.0.1:8766，点击 Start demo → Run automatically。Inspector 会展示编号元素、operation 概率、target 概率与已执行动作；Choose next 会在执行前暂停。

3）浏览器连接排障

Chrome 通过 Browser Harness 连接，由 uv sync 一并安装。若连接异常：

uv run browser-harness --doctor

按提示在 Chrome 中允许远程调试。

4）模型配置说明（README 原文要点）

TEXT_MODEL_API_KEY 在示例配置中是 OpenRouter key；当前 demo 使用 inception/mercury-2.5 且关闭 reasoning。Gemini、GLM、DeepSeek 也可通过 OpenAI 兼容的 text helper 使用，需自行配置对应 model、endpoint 与 reasoning 设置。

三、作为库调用

from jev_ultrafast import Agent

with Agent(
    "https://www.google.com/travel/flights?hl=en",
    "Find one-way flights from Zurich to London on September 20, 2026, "
    "for one adult in economy. Stop when matching flight options are visible.",
) as agent:
    for state in agent.run():
        print(state["elapsed_ms"], state["status"])

uv run --env-file .env python your_script.py

README 另给出两个可运行示例入口：

uv run --env-file .env python examples/run.py \
  --url https://en.wikipedia.org/wiki/Main_Page \
  --goal 'Find and open the Wikipedia article about Gödel’s incompleteness theorems.'

uv run --env-file .env python examples/flights.py --keep-open

⚠️ 注意：这两个示例会发起真实付费 API 调用；flights.py 只做搜索与校验，不选座、不下单。
