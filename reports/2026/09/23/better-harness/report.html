一、项目概览

Better Harness（QoderAI/better-harness）是一个面向 AI 编码代理（coding agent）的 Harness Engineering 开发者工具平台——以「harness-as-code」方式定义代理工作循环（Agent Work Loop），运行受控实验、检视证据并对比结果，最终将任务证据转化为可执行的团队与组织级改进洞察。

  • 项目定位：开源插件/SDK（Open Core 生态，绑定商业宿主 Qoder Desktop 内嵌），本地部署（coding agent 插件/CLI 本地运行，报告为本地 HTML/Markdown）
  • 技术领域：AI 编码代理工作流工程 / Agent 可观测性与评估
  • 目标用户：全栈开发者、AI/ML 工程师、架构师/技术管理者（CTO）
  • 技术栈：多语言 monorepo（TypeScript 78,318 行 + Rust 41,063 行 + TSX 19,076 行，共 143,229 行 / 693 文件），MIT 协议
  • 宿主适配：10+ 编码代理宿主（Claude Code、Codex、Qoder、Cursor、GitHub Copilot、Qwen Code、Pi、Kimi Code、WorkBuddy、Grok）
  • 社区规模：2,320 Star、186 Fork、32 贡献者、90 天 144 PR、近 30 天 279 commits
  • 生命周期阶段：无（lifecycle_stage 为空，未标注阶段）

二、按宿主安装（命令均取自 README 原文）

Qoder Desktop / Qoder CLI（零安装）——Better Harness 已内置于 Qoder 桌面应用，无需 Marketplace 或本地插件安装。可直接在会话中执行：

/better-harness analyze this project's AI coding workflow and generate an evidence-backed report

Qoder 1.18.0+ 也可从 Quest 左侧边栏选择 Better Harness (Beta)。仅在未安装 Qoder Desktop 的 Qoder CLI 环境下才需手动安装：

qodercli plugin marketplace add 'https://github.com/QoderAI/better-harness.git'
qodercli plugin install better-harness@better-harness
qodercli plugin list

Claude Code

/plugin marketplace add QoderAI/better-harness
/plugin install better-harness@better-harness

claude plugin details better-harness@better-harness

新开 Claude 会话后执行 /better-harness analyze this project's AI coding workflow and generate an evidence-backed report。默认在仓库 .claude/better-harness 报告根下产出 report.html、report.md、findings.json。

Codex CLI

codex plugin marketplace add \
  'https://github.com/QoderAI/better-harness.git' \
  --ref main
codex plugin list --marketplace better-harness
codex plugin add better-harness@better-harness

调用提示为 $better-harness:better-harness analyze this project's AI coding workflow and generate an evidence-backed report。Codex Desktop 则通过 Settings > Plugins > + Add > From Marketplace，填入仓库 URL、Git ref（main）、Sparse paths 留空，添加后安装 Better Harness。

GitHub Copilot CLI

copilot plugin install better-harness@better-harness

Cursor——插件未发布到 marketplace，README 明确其安装计划为「unavailable」，仅给出如下非执行型计划命令：

git clone https://github.com/QoderAI/better-harness.git
