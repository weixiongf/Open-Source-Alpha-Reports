二、安装部署与使用指南

OpenViking 提供「零安装在线体验 → 本地 pip 单命令安装 → Docker 容器化部署」三档递进的接入路径，整体上手门槛为简单等级。普通开发者可在 30 分钟内完成从安装到首次检索的完整流程，非技术背景用户亦可先通过浏览器体验 Live Demo 再决定是否部署。

路径一：零安装在线体验（无需任何操作）

直接打开浏览器访问 OpenViking Studio——官方托管的实时演示环境，包含上下文 playground、语义检索与多 Agent 中心，无需安装任何软件即可体验核心功能。

路径二：本地 pip 安装（最简部署，适用于个人开发者）

前置要求：Python 3.10 及以上。官方安装命令（摘自 README Quick start）：

pip install openviking --upgrade
openviking-server init      # interactive wizard: providers, models, ov.conf
openviking-server doctor    # validate setup
openviking-server           # start (background: nohup openviking-server > openviking.log 2>&1 &)
  • init 为交互式向导，自动写入 ~/.openviking/ov.conf，支持 Volcengine、OpenAI、Codex OAuth、Kimi、GLM 及本地 Ollama（Ollama 可自动检测安装运行时并拉取适配硬件配置的模型）。
  • doctor 在服务启动前校验配置文件、Python 版本、provider 连通性与磁盘空间。
  • 安装包已内置 ov 客户端 CLI，无需单独安装。

服务启动后即可使用客户端命令（摘自 README）：

ov status
ov add-resource https://github.com/volcengine/OpenViking # --wait
ov ls viking://resources/
ov tree viking://resources/volcengine -L 2
ov find "what is openviking"
ov grep "openviking" --uri viking://resources/volcengine/OpenViking/docs/en

路径三：Docker 部署（推荐生产使用）

官方提供开箱即用的 docker-compose.yml，核心服务仅一个镜像（ghcr.io/volcengine/openviking:latest），启动命令为 docker compose up -d。数据持久化通过卷挂载 ~/.openviking:/app/.openviking 完成，无需额外初始化数据库/缓存等外部组件。可选配置项通过 .env 注入（如 OPENVIKING_SERVER_PORT、OPENVIKING_PUBLIC_BASE_URL、OV_ACME_EMAIL）。首次启动若 ov.conf 不存在，可通过 docker exec 运行 openviking-server init，或通过 OPENVIKING_CONF_CONTENT 环境变量直接传入完整 JSON 配置。

可选扩展：VikingBot（AI Agent 框架）

pip install "openviking[bot]"
openviking-server --with-bot
ov chat   # in another terminal

平台覆盖：Windows/macOS/Linux 均支持。官方提供 macOS（arm64/x64）与 Windows x64 的桌面控制台 OpenViking Helper（Beta），可可视化完成本地 Agent 检测、插件/MCP/Hook 配置、会话轨迹检视与记忆/技能管理。Windows 安装细节见官方 Configuration guide。

D2.1 产品设计与创新性（1.5/1.5）

"Self-evolving Context Database for AI Agents"是全新产品品类，将 Agent Memory、知识库 RAG 与 Skills 统一为可自我演进的上下文数据库，区别于传统向量数据库（Pinecone/Weaviate）或纯记忆框架（Mem0）。产品设计亮点包括：RAGFS 文件系统抽象（以 git 式接口操作上下文）、dsh-plugin/agent-plugins 生态（覆盖 Claude Code、Codex、Cursor、OpenWebUI、OpenClaw 等十余种 Agent 平台）、Working Memory V2 结构化记忆管理、基于 LLM 驱动的记忆提取与策略训练（compressor_v3、StreamingMemoryUpdater）。相比同类项目差异化明显，创新度高。

D2.2 架构设计与工程质量（1.6/2.0）

D5.3 切换成本与用户粘性（满分 2 分，得分 1.4 分）
