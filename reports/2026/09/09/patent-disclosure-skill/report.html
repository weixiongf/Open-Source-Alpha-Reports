评估概述

本项目是面向中国专利撰写全流程的 Claude Code/Obsidian Skill 套件（7 个子 skill），并非传统软件产品，而是「提示词工程 + 工具链」混合体。评估基于 GitHub API 实测数据、本地 165 文件/43475 行代码的全量扫描及 P1 代码摘要。

该项目的产品设计深度远超同类 AI 辅助专利工具——覆盖交底书→申请文件→OA 答复→专利解读→政策情报→流程管理（docket）全生命周期，且每个环节都有配套的工程化工具链支撑（Word 公式 OMML 转换、STEP CAD 视图渲染、CNIPA 爬虫、附图标注、线稿门禁、向量检索案例库等），而非简单套壳 LLM 提示词。技术护城河来自专利领域知识与工具链的结合，复刻难度较高。主要短板体现在跨 skill 的代码重复（如 md_to_docx.py 存在 3 份 95% 相同的副本）、缺少含测试的 CI 流水线、无正式版本发布。
