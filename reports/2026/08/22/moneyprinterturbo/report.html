Docker 部署（推荐隔离环境）

cd MoneyPrinterTurbo
docker compose -f docker-compose.release.yml up

默认推荐 docker-compose.release.yml，直接拉取 GHCR 预构建镜像 ghcr.io/harry0703/moneyprinterturbo:latest。首次启动前需将 config.example.toml 复制为 config.toml 供挂载。

启动后访问： - WebUI：http://127.0.0.1:8501 - API 文档：http://127.0.0.1:8080/docs 或 http://127.0.0.1:8080/redoc

手动部署（uv 推荐）

git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
uv python install 3.11
uv sync --frozen

启动 WebUI： - Windows：.\webui.bat - macOS/Linux：sh webui.sh

启动 API 服务：

uv run python main.py

CLI 命令行（无浏览器）

uv run python cli.py --video-subject "人工智能如何改变日常生活"

关键配置说明

  • 首次启动时自动根据 config.example.toml 创建 config.toml，无需手写配置文件
  • 大模型 Provider、素材来源和 API Key 直接在 WebUI「基础设置」中图形化配置
  • 默认使用免费 Edge TTS（WebUI 显示为 Azure TTS V1），无需 API Key
  • 字幕默认 edge 模式（TTS 时间戳生成，免 GPU）；可切换 whisper 模式（约 3 GB 模型，需下载）

常见问题快速修复

  • RuntimeError: No ffmpeg exe could be found：从 https://www.gyan.dev/ffmpeg/builds/ 下载 ffmpeg，在 config.toml 中设置 ffmpeg_path
  • OSError: [Errno 24] Too many open files：执行 ulimit -n 10240 调高文件数限制
  • Whisper 模型下载失败：从 Hugging Face 手动下载后放入 .\MoneyPrinterTurbo\models\whisper-large-v3
