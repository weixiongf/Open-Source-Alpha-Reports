1.3 一句话定位

Pathway ARC Task Generator 是一个数据与AI任务生成工具，适用于AI模型评估与基准测试场景，主要面向AI/ML研究人员和评测工程师，用于生成与公开ARC-AGI-1评测集分布匹配的全新任务以避免数据污染。

二、安装部署与使用指南

该仓库目前未提供一键安装入口，也未包含任何容器化部署配置。依据本地实测数据，项目为纯 Python 实现（5 个 .py 文件，共 1890 行），依赖清单为空，预期仅需标准 Python 环境即可运行。

  • 获取方式：从 GitHub 仓库获取源码，仓库内依赖自包含，无 requirements.txt 等外部依赖声明。
  • 运行指引：README 明确要求用户“Follow the instructions in instructions.md to start generating tasks.”，即安装后需依赖该文档完成生成任务的操作配置。
  • 输出物：生成标准 ARC 格式的 tasks.json（README 原文格式：{"train": [], "test": []}），并可接入现有 ARC 评估 harness。
  • 部署说明：无 Dockerfile、无 CI 配置、无快速验证脚本，目前不具备一键部署条件。
