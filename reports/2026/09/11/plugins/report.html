上手路径(中等难度,关键步骤)

  1. 通过 Codex 宿主环境加载本仓库的 marketplace(.agents/plugins/marketplace.json),而非执行仓库级安装。
  2. 按需选定目标插件,阅读其 SKILL.md(如 plugins/build-ios-apps/skills/ios-app-intents/SKILL.md 及 references/ 下的细分文档)。
  3. 若插件附带 requirements.txt 或 package.json,先完成该插件的依赖安装;若涉及 MCP,还需配置对应的 .mcp.json 与凭证。
  4. 使用插件内 package.json 声明的脚本做本地验证(如 npm run dev / npm run build)。
  5. 自定义插件开发可参考 .agents/skills/plugin-creator/SKILL.md 与 .agents/skills/plugin-creator/references/plugin-json-spec.md。
