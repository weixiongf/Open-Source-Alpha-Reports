1.3 一句话定位

FreeLLMAPI 是一个开源 LLM API 聚合与路由中间件，适用于通用跨行业的个人开发与 AI 应用原型验证场景，主要面向后端开发者、全栈开发者及 AI 爱好者，用于将 34 个免费 LLM 提供商的 635 个模型端点统一为一个 OpenAI 兼容 API，并提供智能路由、自动故障转移和密钥加密管理。

二、安装部署与使用指南

FreeLLMAPI 上手路径极短，官方提供了三条互不依赖的安装路径：Docker 一键脚本（推荐，Linux/服务器）、桌面应用安装包（Windows/macOS 零配置）、源码运行（Node 20+ 开发者）。

方式一：Docker 一键脚本（推荐）

curl -fsSL https://freellmapi.co/install.sh | bash

脚本自动完成 ~/freellmapi 初始化、加密密钥生成、镜像拉取与容器启动。重复执行安全：.env 与加密密钥保留，容器更新至 :latest。前置条件仅需本机已安装 Docker。

方式二：桌面应用（Windows / macOS）

从 GitHub Releases 下载 .exe（Windows）或 .dmg（macOS）安装器，随每个版本附送。无需账户密码，启动后唯一的凭据就是托盘弹窗中的 unified API key。

方式三：Docker Compose 自托管

仓库自带 docker-compose.yml，镜像为 ghcr.io/tashfeenahmed/freellmapi:latest，默认仅绑定 127.0.0.1:3001（安全默认，单用户设计），数据持久化至 freellmapi-data 命名卷，内置健康检查与 restart: unless-stopped。需局域网访问时设置 HOST_BIND=0.0.0.0。

首次使用（分钟级）

  1. 浏览器打开 http://localhost:3001
  2. 在 Keys 页面添加各免费提供商的 API keys
  3. 按需在 Fallback Chain 调整路由优先级
  4. 从 Keys 页头部复制 unified API key
  5. 将任意 OpenAI SDK 的 base URL 指向 http://localhost:3001/v1 即可

接入主流编码代理（一条命令）

npx freellmapi setup-claude --url http://localhost:3001 --api-key <unified-key>

同类生成器覆盖 Codex、Cline、Continue、Aider、OpenCode、Goose、Qwen Code、Roo/Kilo/Crush、DeepSeek Harness、MiMo Code 等 13+ 工具，均支持 --dry-run、自动备份、合并现有配置。Claude Code 与 Codex 另有零持久化启动器（npx freellmapi launch / npx freellmapi launch-codex），凭据仅注入子进程、不落盘。

注意：项目定位为个人实验用途，默认绑定 localhost；LAN 访问需显式设置 HOST_BIND=0.0.0.0。生产用途请替换为付费 API。
