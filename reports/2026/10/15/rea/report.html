二、安装部署与使用指南

【注意】本章节为降级概要（安装指南草稿缺失），要点来自 D9 评分卡：

  • 一键安装体验优秀：npm 单包分发，npx rea-agents setup 单条命令完成安装与 agent 的 MCP 注册，39 个 runtime 依赖随包自包含，无需初始化数据库/缓存/消息队列等外部组件。
  • 无容器化交付是主要短板：仓库无 Dockerfile，也无 docker-compose/Helm，部署形态仅为本地 npm CLI + MCP stdio 服务，缺少 docker run 级别的交付方式。
  • 存在免 provider 的 10 分钟验证路径：静态 JavaScript/Electron 与 .NET 检查无需原生分析引擎，npx -y rea-agents@latest analyze-javascript-application <path> --json 可直接产出结果。
  • 完整能力门槛较高：原生分析需 Hopper/Ghidra/IDA（商用工具含授权约束），并需按目标引入 pwntools、JADX+JDK、WABT、Apktool、Binwalk/Unblob、TShark、sigrok-cli、mitmdump、adb 等外部工具；Node 版本被锁定为 ^22.19.0 || ^24.11.0 || >=26.0.0。
  • 入门资料丰富但可复制代码示例偏少：20 种语言 README、142 个文档文件、3 个实战 showcase，但仓库内示例代码仅 9 个文件，且逆向领域知识构成非专家使用门槛。

规模效应：中等。目标覆盖数量与 provider 矩阵随规模扩大而提升体验，但成本侧（本地运行、用户自备引擎）未见显著规模成本优势。

综合：无专利/算法/数据壁垒，MIT 易 fork；网络效应为生态型、非数据型，强度中等。判定为「有一定壁垒但不深厚」，取 5–6 档。

D5.3 切换成本与用户粘性

安装部署与使用指南（D9 上手难度：🟢 简单）

判定依据：项目以 npm 单包分发（rea-agents），一键命令完成安装与 agent 注册，无数据库/缓存/消息队列等外部组件需要初始化，核心链路（安装 → 配置 agent → 首次分析）可在分钟级跑通；扣分项为 Node 版本要求严格、无容器化镜像、深度原生分析需外部引擎。以下命令与配置项均取自 README / package.json 原文。

前置项 要求（素材原文）

npx rea-agents setup

无需任何原生分析引擎即可验证的第一个任务（静态 JavaScript/Electron 应用分析）：

npx -y rea-agents@latest analyze-javascript-application /absolute/path/to/app --json

结果包含 modules、imports、Electron 边界及其证据。Windows 下把路径换成目标路径（README 示例："D:/apps/example"）。

四、升级

rea update

（npm install --global / bun add --global 安装的 CLI；Bun 需 1.2.17 或更高版本）

npx rea-agents@latest setup

（npx 方式安装的 agent setup；Bun 用户以 bunx rea-agents@latest 替代）

升级后按 update 输出的 setup 命令刷新 agent 注册与 skill，并重启 agent。

五、部署形态说明

  • 无容器化交付：仓库内无 Dockerfile，也无 docker-compose / Helm Chart，部署形态为「本地 npm 包 + MCP stdio 服务」，本地分析、不上传目标（README FAQ：REA analyzes targets locally）。
  • 无外部组件初始化：无数据库 / 缓存 / 消息队列依赖；原生 SQLite 读取能力依赖 Node.js 24.x >=24.15 或 26+ 的内置 SQLite 限制。
  • 可选 provider 配置：深度原生分析需先配置 provider（Hopper 可由 setup 在批准后安装；Ghidra/IDA 使用你已有的安装）。大二进制可调启动超时：
  • REA_GHIDRA_STARTUP_TIMEOUT_MS
  • REA_HOPPER_STARTUP_TIMEOUT_MS
  • JEB provider 通过 REA_JEB_MCP_URL 选择（需调用方自行启动 JEB 客户端并使其以 MCP 服务）
  • 按目标按需引入的外部工具（非安装必选项，仅对应目标类型需要）：pwntools（Linux x64）、WABT 1.0.42、JADX + 完整 JDK、adb、Apktool、Binwalk / Unblob（Linux）、TShark 4.x + prlimit、sigrok-cli 0.7.2 + prlimit、mitmdump（Linux）、GDB/pwndbg（可选）。
