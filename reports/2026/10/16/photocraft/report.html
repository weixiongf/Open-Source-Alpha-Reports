一、项目概览

  • 项目：storytold/photocraft —— PhotoCraft: An open-source, photo editor written by scratch in pure Rust
  • 一句话定位：PhotoCraft 是一个开源、纯 Rust 实现的 Photoshop 级图像编辑应用（clean-room 重写），适用于媒体内容、设计、摄影等跨行业创意场景，主要面向设计师/摄影师/艺术家等创意用户及需自动化图像处理的开发者与 AI Agent，用于在本地离线、跨平台完成图层/蒙版/文字/矢量/PSD 等专业图像编辑与批处理自动化。
  • 分类属性：应用软件；行业为通用/跨行业（媒体内容·设计·摄影）；模式为「本地部署开源应用 + CLI/SDK 可编程（含 WebAssembly 托管网页版）」；部署形态为本地部署 + 混合部署（桌面原生 / 浏览器 WebAssembly）；技术域为 Rust · GPU 合成（wgpu）· 图像处理 · clean-room 重实现；变现距离为「中」——项目本身 MIT/Apache 双许可无直接收费，变现依赖母品牌 ArtCraft/getartcraft.com 承载托管与增值服务。

二、安装部署与使用指南

上手难度等级：🟢 简单（D9 = 8.0/10）——提供全平台预编译安装包，普通用户可用；从源码构建面向开发者。

一、面向普通用户（推荐）

PhotoCraft 在 macOS、Windows、Linux、FreeBSD 和 Web 上均有预编译安装包：

  • 官方下载页：README 明确「New to PhotoCraft? Download it from the PhotoCraft page on getartcraft.com. That's the easiest way to install it.」
  • GitHub Releases：「Installers for macOS, Windows, Linux, FreeBSD and the web are attached to each [GitHub release]」，Windows 另有 windows-arm64 构建。

二、Linux 各安装形态

README 列出的 Linux 安装包为 AppImage、.deb、.rpm、tarball 或 Flatpak bundle。AppImage 无需安装：

The AppImage needs no install: the first run registers its launcher icon and menu entry in ~/.local/share so the dock shows PhotoCraft's icon on Wayland. Set PHOTOCRAFT_NO_DESKTOP_INTEGRATION=1 to skip that.

Flatpak（需 Flathub 的 freedesktop runtime）：

flatpak install --user photocraft-<version>-linux-x86_64.flatpak   # or -linux-aarch64
flatpak run ai.storyteller.photocraft

三、macOS 命令行工具（photocraft-cli）

CLI 以 photocraft-cli-<version>-macos-universal.zip 提供，已由 Apple 公证：

ditto -x -k photocraft-cli-<version>-macos-universal.zip .
spctl --assess --type install -vv photocraft-cli-<version>-macos-universal/photocraft-cli

四、FreeBSD 14 (x86_64)

先装运行时库，再解包到 /usr/local：

pkg install libxkbcommon wayland libX11 libXcursor libXrandr libXi libxcb mesa-libs vulkan-loader gtk3 fontconfig freetype2 alsa-lib

五、Web 版自托管（Docker）

To self-host the browser version with Docker, see Docker web hosting.

仓库内 Dockerfile 为社区维护的自托管配方：builder 阶段（rust:${RUST_VERSION}-slim-bookworm）安装 wasm target 并用 trunk build --release --locked 构建，runtime 阶段基于 nginx:1.28-alpine 托管静态站点，暴露 8080 端口并带 HEALTHCHECK。

六、从源码构建（开发者）

前置条件：Rust（rust-version = "1.95"，edition = "2024"）。标准步骤：

git clone https://github.com/storytold/photocraft
cd photocraft
cargo run --release -p photocraft -- image.psd   # the desktop app
cargo test --workspace                           # the test suite

如需日文字体（可选构建输入）：

git clone https://github.com/storytold/craft-fonts ../craft-fonts
CRAFT_FONTS_DIR="$PWD/../craft-fonts" cargo run --release -p photocraft

七、日常使用

桌面 GUI：菜单、快捷键、面板与 Photoshop 一致（README：「If you know Photoshop, you already know PhotoCraft」），另有命令面板 ⌘F。

无头 CLI（photocraft-cli）——来自 README 的原始示例：

# Headless: open, edit, save
photocraft-cli run wave.psd \
  --cmd filter.sharpen.smartSharpen     --params '{"amount":80}' \
  --cmd layer.newAdjustmentLayer.curves --params '{"points":[[0,0],[64,48],[192,212],[255,255]]}' \
  --out wave-final.png

# Apply one action list to a folder of images
photocraft-cli batch --actions grade.json --in ./raw --out ./graded

# Every subcommand explains itself
photocraft-cli batch --help

# Let an agent drive it over MCP (headless, or bridged to the running app)
photocraft-cli mcp

运行中应用的受控通道：photocraft --control（仅回环、需认证），详见 docs/control-protocol.md。

测试语料（可选）：

cargo xtask corpus --all
cargo xtask test-corpus

八、已知注意事项

  • Wayland：文件拖拽暂不可用（winit 0.30 限制，#386），改用 File › Open 或 Ctrl+V 粘贴；如需拖拽可在 XWayland 下运行：WAYLAND_DISPLAY= photocraft。

结论

PhotoCraft 的法律基础总体稳健：MIT OR Apache-2.0 双许可、无 copyleft、无商业附加条款、依赖链无传染性协议，为闭源衍生、SaaS 托管、企业授权等主流变现路径扫清了协议障碍，构成显著合规优势。主要风险与不确定性为三处：① 商标/专利未经专业核查（置信度低）；② 两个内部 git 依赖（craft-libs）的许可状态未验证；③ 无 CLA，版权分散导致未来难以重新许可。
