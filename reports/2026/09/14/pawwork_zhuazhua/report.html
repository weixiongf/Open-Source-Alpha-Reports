优势（拉高项）

  1. 零后端部署：项目形态为 Chrome MV3 unpacked 扩展，README 与描述均明确 "BYOK, sandboxed, no server"。整个部署链路不涉及服务器、数据库、缓存或消息队列的初始化，本地实测依赖清单为空（dependencies: {}），也无 Dockerfile / CI workflow——因为确实不需要。这在同类 AI Agent 项目中属于显著的低摩擦项。

劣势（拉低项）

  1. 分发渠道缺失导致安装非一键：项目未上架 Chrome Web Store（README「Limits」表格首行即 "CWS install | No. Unpacked only."），用户必须自行完成「下载/克隆 → 开发者模式 → Load unpacked → 选择目录」的手动链路。相较 docker run 或应用商店一键安装，这是明确的第一道转化漏斗损失。
