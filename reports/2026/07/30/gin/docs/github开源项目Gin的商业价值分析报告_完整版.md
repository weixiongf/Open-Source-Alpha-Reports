### 2.2 安装部署步骤

方式一：Go Module 自动安装（推荐，取自 README 原文）

```go
import "github.com/gin-gonic/gin"
```

构建时 Go 自动拉取依赖，无需任何手动安装步骤。

方式二：最小可运行示例（README 原文示例）

```go
package main

import (
  "log"
  "net/http"

  "github.com/gin-gonic/gin"
)

func main() {
  r := gin.Default()
  r.GET("/ping", func(c *gin.Context) {
    c.JSON(http.StatusOK, gin.H{"message": "pong"})
  })
  if err := r.Run(); err != nil {
    log.Fatalf("failed to run server: %v", err)
  }
}
```

```sh
go run main.go
# 浏览器访问 http://localhost:8080/ping，返回 {"message":"pong"}
```

### 2.3 基本使用

- 快速上手：`gin.Default()` 创建带日志与恢复中间件的路由器，注册路由即可启动
- 核心功能入口：路由分组（`RouterGroup`）、中间件链、模型绑定与校验（`binding`）、多格式渲染（`render`）
- 常用配置：`gin.SetMode(gin.ReleaseMode)` 切换生产模式；中间件生态见 gin-contrib
