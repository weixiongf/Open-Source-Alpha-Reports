1. 项目形态与"部署"含义

本仓库不是可运行的服务或应用，而是论文（"Finite time blowup for Navier–Stokes"、"Finite time blowup for the Euler equation"）的 Lean 4 形式化证明证书（certificates）。所谓"部署"实为在本机构建并通过 Lean 类型检查（proof checking），不涉及数据库、缓存、消息队列等外部服务组件。

2. 环境要求（README 原文）

The project uses Lean 4.34.0-rc2, Mathlib, and Lake. With elan installed, fetch the mathlib cache and build the formalizations with:

lake exe cache get
lake build

3. 前置条件与依赖要点

  • 需先安装 elan（Lean 工具链管理器，README 外链提供）；
  • 需按仓库锁定版本拉取 Lean 4.34.0-rc2（RC 版本）工具链与 Mathlib 预编译缓存，体量较大，依赖稳定网络与充足磁盘；
  • 仓库未提供 Dockerfile / docker-compose / Helm Chart / CI 工作流，无容器化或一键脚本捷径；
  • 本地实测未检出依赖清单文件（无 requirements.txt / package.json / go.mod 等），依赖关系由 Lake 构建描述隐式承载。

4. 部署核验方式
