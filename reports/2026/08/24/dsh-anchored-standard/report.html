二、安装部署与使用指南

⚠️ 上手难度评估：🔴 复杂（1.6/10）——仅限开发者使用

本项目是 DeepSeek Harness 的插件预设，不是独立可运行的软件。使用前必须自行安装并配置 DeepSeek Harness（0.1.0-rc.5，commit 47f9438）及 Node.js ≥ 22.19.0 环境。以下为安装部署方案概要，具体操作请开发者依据官方文档执行。

安装概要

每模式目录自包含，需手动复制到用户预设根目录。以 base 模式 preset/ 为例（PowerShell / Linux 命令原文）：

# PowerShell
$target = Join-Path $env:USERPROFILE '.dsh\.agent-presets\anchored-standard'
if (Test-Path -LiteralPath $target) { throw "Preset already exists: $target" }
New-Item -ItemType Directory -Force -Path (Split-Path -Parent $target) | Out-Null
Copy-Item -Recurse -LiteralPath '.\preset' -Destination $target

# Linux/macOS
dsh_home="${DSH_HOME:-$HOME/.dsh}"
mkdir -p "$dsh_home/.agent-presets"
test ! -e "$dsh_home/.agent-presets/anchored-standard"
cp -R preset "$dsh_home/.agent-presets/anchored-standard"

复制完成后需完全重启 DeepSeek Harness，创建空白会话，选择对应预设模式。其余 6 个变体目录（zero-anchored-standard/、whoami-standard/、prefab/、eternal-minimal/、wire-think-standard/、combo-anchored/）安装方式相同。prefab/ 模式推荐通过 AI 编码代理按 prefab/AGENT_INSTALL.md 契约执行一键式安装。

验证与测试

验证需导出会话 JSONL 并人工检查 request/header 事件（核对 maxTokens 值、首请求工具 schema、注入抑制、晋升后 resident catalog 四项）。运行本地测试：

npm test

技术要点

  • 前置依赖：DeepSeek Harness 0.1.0-rc.5（当前为 developer preview，允许破坏性变更）+ Node.js ≥ 22.19.0（引擎要求见 package.json），零运行时依赖包（dependencies: {}）。
  • 配置复杂度：每个模式核心配置在 agent.cordis.yml，涉及 context-gate、tool-bootstrap、anchor-turn、cot-drip、toolchoice-adapter、wire-think 等多个插件行，未知配置键会在预设挂载时直接报错。
  • 无容器化支持：仓库无 Dockerfile / docker-compose / Helm Chart。
  • 维护状态：项目自 2026-08-17 起停止活跃开发，仅维护（README 明确声明）。
