二、安装部署与使用指南

本项目核心价值为「532 个逆向工程案例 + 20+ 套工业级提示词模板」，零安装即可使用；Agent Skill 组件支持单命令安装；官方已托管线上可视化网站，一般无需自部署。

路径一：零安装使用（推荐，所有用户）

  1. 打开案例画廊 docs/gallery.md（或线上站 https://gpt-image2.canghe.ai），按 UI、海报、摄影、电商等 13 个分类浏览 532 个案例；
  2. 选定目标案例，复制完整提示词，将业务变量填入 docs/templates.md 中的 20+ 套模板；
  3. 在 ChatGPT / GPT-Image2 中生成。

README 官方三步指引：

  1. Start from the featured cases and decide what output type you want to imitate.
  2. Open the full gallery and find nearby cases. Copy structure first, then style words.
  3. Return to the template page and fill your business variables into the general or JSON templates.

路径二：安装 Agent Skill（开发者 / Agent 用户）

Claude Code / Codex / Cursor 等支持的一条命令安装：

npx skills add freestylefly/awesome-gpt-image-2 --skill gpt-image-2-style-library --agent claude-code codex --global --yes --copy

安装至全部支持的本地 agent：

npx skills add freestylefly/awesome-gpt-image-2 --global --all --copy

npm CLI 方式：

npm install -g gpt-image-2-style-library
gpt-image-2-style-library install all

安装完成后重启 agent 会话，用自然语言请求即可，如：

Use gpt-image-2-style-library to create an infographic prompt about Codex.

Claude Code 插件市场方式（在 Claude Code 内执行）：

/plugin marketplace add freestylefly/awesome-gpt-image-2
/plugin install gpt-image-2-style-library@awesome-gpt-image-2

路径三：本地运行网站（开发者，可选）

npm run dev   # predev 自动执行 generate:site-data 与 generate:style-skill

完整自部署需准备 Supabase、Stripe、支付宝、GA4 等外部服务，配置 14 个环境变量并应用 8 个 SQL migration（详见 README "Website Auth & Generation" 章节）。一般用户无需自行部署——官方线上站 gpt-image2.canghe.ai 已托管全部功能，支持浏览、复制、筛选及 Google 登录后测试生成。
