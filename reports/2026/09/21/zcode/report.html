2. 源码安装（关键步骤）

# 一步初始化：安装 workspace 依赖 + 准备桌面本地运行资源 + build:bootstrap
pnpm bootstrap

pnpm bootstrap 默认跳过远程资源准备，适合本地桌面开发。需要远程工作区（SSH/WSL）或验证远程发行资源时改用：

pnpm bootstrap:with-remote

其他可选入口：

pnpm install                 # 仅安装依赖
pnpm prepare:desktop-runtime # 准备桌面运行资源（默认含远程资源）
pnpm prepare:remote-assets   # 单独准备远程运行资源
pnpm build                   # 递归构建各 workspace 包

Agent CLI 与运行时源码位于 apps/zcode-cli/，随本仓库一起克隆，无需单独拉取或初始化 Git submodule。

3. 运行（三种入口）

# 桌面版（Electron）
pnpm dev:desktop          # 等同于 pnpm dev:desktop:prod，使用生产服务配置
pnpm dev:desktop:test     # 使用测试环境
ZCODE_DATA_BASE_DIR="$HOME/.zcode-dev-home" pnpm dev:desktop:test

# Web 工作台（同时起 Web 开发服务器 :5173 与后端 :3030）
pnpm dev:web
ZCODE_SERVER_WORKSPACE=/path/to/project pnpm dev:web

# 直接开发 TUI / Agent 源码
pnpm --filter @zcode/cli dev
pnpm --filter @zcode/cli dev --help

构建 CLI 及其 workspace 依赖后可直接运行：

pnpm --filter @zcode/cli... build
node apps/zcode-cli/packages/cli/dist/zcode.cjs --help

4. 发行包（命令行版）与本地验证

命令行发行包内含 TUI、Web 与 Agent，统一用 zcode 启动。pnpm build:zcode 只生成发行包，不会替换 PATH 中已有的 zcode。

# 打包前必须设置下载根地址 ZCODE_DIST_BASE_URL（或通过 --base-url 传入）
pnpm build:zcode --base-url https://downloads.example.com/zcode/
pnpm build:zcode            # 已配置 ZCODE_DIST_BASE_URL 时
pnpm build:zcode --skip-build  # 仅重新组包，复用已有构建产物
pnpm build:zcode --help

默认输出目录为 dist/zcode/，产物包括：

  • releases/<version>/zcode-<version>.tar.gz：运行包
  • releases/<version>/sha256.txt：校验摘要
  • latest.json、install.sh：版本索引和安装脚本

构建产物需自行上传到配置的下载根地址；安装脚本从该地址下载运行包，默认安装到 ~/.zcode/runtime，并在 ~/.local/bin 创建 zcode 命令（目录可用 ZCODE_DIST_HOME / ZCODE_DIST_BIN_DIR 修改）。

不上传、直接本地验证：

zcode_version=$(node -p "require('./dist/zcode/latest.json').version")
mkdir -p dist/zcode/debug
tar -xzf "dist/zcode/releases/$zcode_version/zcode-$zcode_version.tar.gz" \
  -C dist/zcode/debug
# 默认启动 TUI
node dist/zcode/debug/zcode/bin/zcode.mjs

# 启动 Web
node dist/zcode/debug/zcode/bin/zcode.mjs --web \
  --workspace "$PWD" --port 3030 --no-open

浏览器打开 http://127.0.0.1:3030 即可验证同一后端服务托管 Web 页面和 Agent 的完整链路。

5. 最终用户日常命令

zcode                        # 无参数进入 TUI
zcode --web                  # 启动 Web 界面
zcode --web --workspace /path/to/project --port 3030 --no-open
zcode --help
zcode --web --help

Web 模式默认工作目录为当前目录，监听 127.0.0.1，默认不启用访问令牌，自动选择空闲端口并打开浏览器；局域网访问可用 --host 0.0.0.0，监听非本机地址时默认生成访问令牌（可用 --token / --no-token 调整）。直接启动 HTTP 入口时通过 ZCODE_SERVER_AUTH_TOKEN 配置认证。

6. 桌面版打包（可选）

pnpm bundle:desktop
pnpm bundle:desktop -- --os win --arch x64     # --os: mac|win|linux；--arch: x64|arm64
pnpm bundle:desktop -- --help

默认目标为 macOS arm64，输出到 packages/desktop/dist/。安装：双击打开产物 DMG 拖入"应用程序"；本地构建未签名，首次打开被 macOS 拦截时执行：

sudo xattr -rd com.apple.quarantine /Applications/ZCode.app

7. 配置项（.env / .env.local / 环境变量）

根目录 .env.example 提供服务地址与构建配置示例，可按需复制到 .env，本地覆盖放入 .env.local。

配置 用途
ZCODE_DATA_BASE_DIR 应用数据基目录，数据写入其下的 .zcode/
ZCODE_SERVER_WORKSPACE Web 后端的工作区路径
ZCODE_BUILTIN_PROVIDER_CONFIG_FILE 本地 Provider 配置文件路径；未设置时使用内置配置

8. 排障提示（原文）

  • 若 zcode 仍指向旧安装或其他源码目录：macOS / Linux 用 command -v zcode，Windows 用 where.exe zcode 检查。
  • Web 验证端口需空闲；如正在运行 pnpm dev:web，改用其他 --port。
  • 旧 Lite 用户需改用新构建命令与安装脚本；新安装不会删除旧 Lite 目录，也不会迁移已有会话数据。
