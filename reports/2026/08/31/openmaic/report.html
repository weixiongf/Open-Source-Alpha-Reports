二、安装部署与使用指南

快速开始（开发模式）

环境要求: Node.js >= 20.9.0、pnpm >= 10

git clone https://github.com/THU-MAIC/OpenMAIC.git
cd OpenMAIC
pnpm install

安装完成后配置环境变量（至少一个 LLM provider key）：

cp .env.example .env.local

编辑 .env.local，填入至少一个 LLM 提供商密钥：

OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
GOOGLE_API_KEY=...

启动开发服务器：

pnpm dev

打开 http://localhost:3000 即可开始使用。

Docker 部署

cp .env.example .env.local
# 编辑 .env.local 填入 API keys，然后：
docker compose up --build

生产构建

pnpm build && pnpm start

可选组件

组件 启用方式 说明

解决完整度： - 功能完整性较高：支持 12 种界面语言、20+ 种 LLM 提供商、PPTX 导入/导出、HTML 离线导出、视频导出、语音克隆、本地 ASR/TTS 等，是一个准生产级完整方案。 - 从 v0.1.0 到 v1.0.0 的演进路径（基础生成 → 交互模式 → PBL → 编辑器 → Agent 工作台 → 持久化）表明产品在持续补齐完整度。

替代成本： - 替代选择包括：传统课件工具（PowerPoint + 手动制作，费时费力）、其他 AI 课件生成工具（如 ClassPoint AI、SlidesAI、Tome，但大多只生成静态 PPT，不做沉浸式多智能体课堂）、通用 LLM + 手动组装（需要技术能力）。 - OpenMAIC 的差异化在于"多智能体交互课堂"这一形态，市场上直接竞品稀缺，但简单 AI 课件生成工具已较多，用户在"只做 PPT"的需求上替代品充分。

核心结论

OpenMAIC 处在 AI 教育内容生成这一真实且高速增长的市场上，市场时机判断为"恰当"（技术成熟 + 竞争未固化 + 政策利好），这是其最大的商业机会点。项目以 5 个月 23.8k stars 的速度成为该细分领域的头部开源项目，证明了需求的真实性和产品的吸引力。

主要商业风险： 1. 付费意愿未验证：开源社区热度 ≠ 付费意愿。教育市场的采购决策链长（学校/培训机构预算流程），"多智能体课堂"这一新形态尚未进入主流教育采购目录； 2. 替代威胁：大模型平台自带的教育功能（定制 GPT、Projects）、以及传统 PPT 生成工具的快速 AI 化，可能挤压中间层生存空间； 3. 变现路径不明：MIT 协议 + 免费托管服务（open.maic.chat），未见明确的商业版/企业版规划，短期变现通道主要依赖托管服务收费或企业定制。

总体判断：市场需求真实、赛道增长强劲、时机恰当，但"多智能体交互课堂"作为一个新品类，其市场接受度和付费转化存在不确定性——属于"高潜力、待验证"的早期市场机会。
