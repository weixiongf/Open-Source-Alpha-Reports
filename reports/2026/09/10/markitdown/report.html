二、安装部署与使用指南

以下命令与配置均取自项目 README / Dockerfile 原文，未作任何增删。

MarkItDown 是一个 Python 命令行工具，安装与使用均极简。推荐使用虚拟环境隔离依赖：

python -m venv .venv
source .venv/bin/activate

安装（含全部格式支持依赖）：

pip install 'markitdown[all]'

如需从源码安装：

git clone git@github.com:microsoft/markitdown.git
cd markitdown
pip install -e 'packages/markitdown[all]'

基本用法（CLI）：

markitdown path-to-file.pdf > document.md

指定输出文件：

markitdown path-to-file.pdf -o document.md

管道输入：

cat path-to-file.pdf | markitdown

Python API：

from markitdown import MarkItDown

md = MarkItDown(enable_plugins=False) # Set to True to enable plugins
result = md.convert("test.xlsx")
print(result.markdown)

Docker 部署（需自行构建镜像）：

docker build -t markitdown:latest .
docker run --rm -i markitdown:latest < ~/your-file.pdf > output.md

项目最低要求 Python 3.10，无硬性系统级依赖；完整功能（音视频、OCR 等）需按需安装可选依赖或配置 Azure 服务，但日常文档转换开箱即用。

D2.1 产品设计与创新性（1.5 分）→ 1.2 分（80%）

产品理念清晰: MarkItDown 精准定位于「AI 时代的数据管道枢纽」——将 PDF、Word、PPT、Excel、图片、音视频等 20+ 格式统一转换为 LLM 友好的 Markdown。设计思路高度聚焦"格式归一化"这一核心痛点，而非直接做文档解析。

功能设计围绕核心场景: 主包提供 convert() 单一入口，支持本地文件、URL、流、响应对象多种输入；通过 Converter 注册机制将各格式实现解耦；可选依赖（[all] extra）按格式分组，用户可按需安装。核心场景覆盖完整（PDF/Office/HTML/CSV/JSON/图片/音频/EPUB/YouTube/RSS/Wikipedia 等），无显著功能冗余。

模式与体验创新: 采用"核心 + 插件"双轨制——通过 register_converter() 支持自定义格式扩展，社区可直接贡献 markitdown-sample-plugin 作为范例；在 AutoGen、LangChain、OpenAI 生态中被集成（见 Topics），验证了「文档 → LLM 输入」这一模式的行业需求。区别于 pdfplumber、pandoc 等通用转换工具，MarkItDown 专为 GenAI 工作流设计。
