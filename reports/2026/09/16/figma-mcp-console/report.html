1.3 一句话定位

figma-mcp-console 是一个 MCP 服务端（开发者工具/中间件），适用于跨行业的产品设计与研发协作场景，主要面向前端开发者和 UI/UX 设计师，用于让 AI 助手通过本地桥接实时读写 Figma 设计文件（设计转代码、需求转设计、设计令牌同步、批量图层编辑），无需 API token 且不受速率限制。

二、安装部署与使用指南

本项目的分发方式为 npm 包 figma-mcp-console，无需 clone 仓库、无需编译 Go 代码，npx 会自动下载并运行；运行时不需要任何外部服务（无数据库/缓存/消息队列），本地桥接端口固定为 2000 且自动选举/接管，属"零配置"型工具。以下步骤均取自 README 原文。

1. 环境准备（Prerequisites）

  • [ ] Node.js 18+ —— 用 node --version 检查
  • [ ] Figma Desktop 桌面应用（网页版无法运行 development 插件）

2. Step 1 — 把 MCP server 加入你的 AI 工具

无需安装，npx 自动下载并运行。

Claude CLI（单项目），在项目目录内执行：

claude mcp add figma-console -- npx -y figma-mcp-console@latest

Claude CLI（全局所有项目）：

claude mcp add --scope user figma-console -- npx -y figma-mcp-console@latest

写入项目 .mcp.json（同样适用于 .cursor/mcp.json、Antigravity mcp_config.json）：

{
  "mcpServers": {
    "figma-console": {
      "command": "npx",
      "args": ["-y", "figma-mcp-console@latest"]
    }
  }
}

Claude Desktop：Settings → Developer → Edit Config（claude_desktop_config.json）写入上述 JSON 后重启。Windows 上改用：

"command": "cmd", "args": ["/c", "npx", "-y", "figma-mcp-console@latest"]

Codex CLI：

codex mcp add figma-console -- npx -y figma-mcp-console@latest

或 ~/.codex/config.toml：

[mcp_servers.figma-console]
command = "npx"
args = ["-y", "figma-mcp-console@latest"]

VS Code（GitHub Copilot） 新建 .vscode/mcp.json（或 Command Palette → "MCP: Add Server"），并在 Copilot Chat 的 Agent 模式下使用：

{
  "servers": {
    "figma-console": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "figma-mcp-console@latest"],
      "cwd": "${workspaceFolder}"
    }
  }
}

其他 MCP 客户端（opencode、Windsurf、Cline、Gemini CLI、Zed 等）：使用标准 MCP stdio transport，command 设为 npx、args 设为 ["-y", "figma-mcp-console@latest"]。

3. Step 2 — 安装 Figma 插件

先拿到插件目录，二选一：

  • Option A（推荐）：从 GitHub Releases 下载 plugin.zip → 解压
  • Option B：运行 npx figma-mcp-console install-plugin，它会保存插件目录并自动打开以便看到 manifest.json

两种方式之后：

  1. 在 Figma Desktop：Plugins → Development → Import plugin from manifest… → 选择 manifest.json（一次性步骤）
  2. 运行：Plugins → Development → Figma MCP Console，并在工作过程中保持插件窗口打开（🟢 绿点 = 已连接）
  3. 同时处理多个 Figma 文件时，在每个文件里各运行一次插件，所有窗口连接同一个本地 bridge
