一、项目概览

Jev Ultrafast（browser-use/jev-ultrafast）是一个基于「索引化动作空间 + 小模型按需生成文本」的浏览器 AI Agent 库，定位为「Fastest and cheapest web agent」，主要面向后端开发者、AI/ML 工程师与全栈开发者，用于以更低延迟和成本让 LLM 自主完成真实网页任务（比价、检索、表单填写、RPA 替代等）。

  • 主语言 / 协议：Python / MIT License
  • 代码体量：2,032 行 / 17 文件 / 1 贡献者
  • 社区热度：18,985 Star、1,250 Fork（Fork 比率 6.6%）
  • 商业形态：Open Core 双轨（MIT 开源库 + Browser Use Cloud 托管 waitlist）
  • 核心实测指标：同任务中位耗时 9.450s→7.092s（-25%），浏览器协议调用 1,092→101（约 -91%）

项目由知名组织 browser-use 发布，发布首周即获近 1.9 万 Star，属「发布即具背书」型爆发。新项目豁免：无历史不构成停滞证据（项目年龄 6 天 < 90 天，无 archived/deprecated 标记，近 30 天有 commit）。

二、安装部署与使用指南

上手难度等级：🟡 中等（D9 得分 7.0/10） — 面向有技术基础者。以下提供关键步骤，省略 Python/终端基础操作。

环境要求

  • Python >=3.12（pyproject.toml 硬约束）
  • uv 包管理器（安装依赖、运行脚本的统一入口）
  • 本地 Chrome 浏览器（通过 browser-harness 建立远程调试连接）
  • 两个付费 API Key：TYPESAFE_API_KEY（TypeSafe Jev 决策模型）与 TEXT_MODEL_API_KEY（默认指向 OpenRouter）

安装与启动（README 原文命令）

git clone https://github.com/browser-use/jev-ultrafast.git
cd jev-ultrafast
uv sync
cp .env.example .env
# Add TYPESAFE_API_KEY and TEXT_MODEL_API_KEY.
uv run jev

启动后打开 http://127.0.0.1:8766，点击 Start demo → Run automatically。若 Chrome 未连接，README 指引运行：

uv run browser-harness --doctor

并在 Chrome 提示时允许远程调试（Allow remote debugging）。

作为库调用（README 原文示例）

from jev_ultrafast import Agent

with Agent(
    "https://www.google.com/travel/flights?hl=en",
    "Find one-way flights from Zurich to London on September 20, 2026, "
    "for one adult in economy. Stop when matching flight options are visible.",
) as agent:
    for state in agent.run():
        print(state["elapsed_ms"], state["status"])

运行方式：

uv run --env-file .env python your_script.py

部署方案概要

  • 无容器化产物：仓库中无 Dockerfile、无 docker-compose.yml、无 Helm Chart（本地实测 has_dockerfile: false），亦无 CI 工作流（ci_workflows: 0）。部署形态为「本地 Python 进程 + 本地 Chrome」，暂无面向服务器/集群的标准部署路径。
  • 无外部数据库/缓存/消息队列，运行期依赖仅 2 个（见下），初始化工作集中在「API Key 配置 + Chrome 调试连接」两处。
  • 验证性 demo 已内置：uv run jev 即拉起本地 inspector（端口 8766），并在其中一键运行飞行搜索演示。

⚠️ 数据一致性提示：README 引用了 examples/run.py 与 examples/flights.py，但本地实测统计「示例: 0 文件」，二者存在冲突，实际示例可用性需以仓库当前文件树为准。

D1.2 痛点真实性与解决程度
