2. 安装

Pelican 发布于 PyPI（pyproject.toml 中 name = "pelican"，当前版本 4.12.0；README 含 PyPI 徽章指向 https://pypi.org/project/pelican/），使用 pip 安装：

D4.1 协议对变现模式的影响（0.8 / 2）

硬事实： - LICENSE 文件首行为 "GNU AFFERO GENERAL PUBLIC LICENSE Version 3, 19 November 2007"； - pyproject.toml 中 license = { text = "AGPLv3" }，classifier 为 GNU Affero General Public License v3 or later (AGPLv3+)； - 贡献者数 414（GitHub API 实采），仓库未见 CLA（贡献者协议）文件。

评估：AGPL-3.0 属方法论表中的"显著约束"档（GPL/AGPL）。其第 13 条要求通过网络向用户提供修改版服务时开放对应源码，直接压制"基于改进版 Pelican 提供闭源托管服务"这一最主流的 SSG 变现路径。对纯本地 CLI 使用场景而言，AGPL 的实际影响弱于对服务端软件的影响（生成出的静态站点不属于 covered work），因此不至于落到 SSPL/BUSL 一级的 1–2 档；但任何以 Pelican 为核心的商业服务或闭源衍生品均须开源，这在结构上封死了 Open Core 的闭源企业版路线。
