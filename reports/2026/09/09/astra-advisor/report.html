二、安装部署与使用指南

Astra Advisor 是一个 Codex 插件，安装过程即向 Codex CLI / ChatGPT 桌面客户端注册并添加插件仓库。前置条件是已安装支持插件功能的 Codex CLI 或 ChatGPT 桌面客户端。仓库本身无 Dockerfile、无第三方 Python 依赖（本地检测 dependencies 为空），因此不存在传统容器部署或数据库初始化步骤。

安装命令

根据 README「Quick start」章节，安装需依次执行两条命令：

codex plugin marketplace add DannyMac180/astra-advisor --ref main
codex plugin add astra-advisor@astra-advisor

添加完成后，需启动一个新任务，并在任务中选择 GPT-6 Astra 模型。如果已有该插件并需升级，可执行：

codex plugin marketplace upgrade astra-advisor
codex plugin add astra-advisor@astra-advisor

如需本地开发调试，可将本仓库作为本地 marketplace 注册：

cd /absolute/path/to/astra-advisor
codex plugin marketplace add /absolute/path/to/astra-advisor
codex plugin add astra-advisor@astra-advisor

快速验证

安装后启动一个新的 Codex 任务，直接使用以下技能调用语句触发核心编排能力：

Use $astra-advisor:orchestration to plan, build, verify, and review this work.

如果只想验证成本计算器功能，仓库自带示例输入与验证脚本：

python3 plugins/astra-advisor/scripts/cost_receipt.py plugins/astra-advisor/examples/illustrative-usage.json
sh plugins/astra-advisor/scripts/verify.sh

该计算器以 JSON 输出结果，并支持 --pricing PATH 参数指向已验证的价格快照。

注意事项

  • 不存在独立服务进程，所谓“部署”即 Codex 插件注册，实际运行能力由 Codex 宿主提供。
  • 运行涉及 gpt-5.6-sol、gpt-5.6-terra、gpt-5.6-luna 等模型能力，宿主不支持时插件会明确报错，不会静默降级替代。
  • 面向 Codex 用户群体，非 Codex 用户无法直接安装使用。
